# Turar — Sacred Embroidery of Kyrgyzstan

A gallery website for textile artist **Turar Turganalieva**, member of the Union of
Artists of the Kyrgyz Republic. Hand-embroidered ornament — drawn in soap on cloth,
finished in silk. The site is a portfolio/gallery (no e-commerce): collectors inquire
for a price by email.

Built to the Claude Design handoff: **Cormorant Garamond + Manrope**, an ivory
gallery-white palette with a cinnabar accent, a night theme, and a quiet abstract
*tumar* (lozenge) motif.

## Pages

- **`index.html`** — hero, quote band, the Selected Works gallery (click any piece for
  a full-screen lightbox), an artist teaser, and an inquiry section.
- **`about.html`** — the artist's story, written from her podcast interview (two lives,
  eight years at the window, the practice, a language of signs, recognition, the atelier).

## Features

- **Four languages** — EN / RU / ES / FR, each **pre-rendered to its own URL** (`/`, `/ru/`,
  `/es/`, `/fr/`) with `hreflang` alternates, so every language is crawlable and works with
  JavaScript off. The header switcher is plain links.
- **Two themes** — ivory (default) and night, toggle in the header (persists). First visit
  honours the OS `prefers-color-scheme`.
- **Responsive** — masonry gallery collapses to one column; mobile nav menu.
- **Lightbox** — full-screen viewer with keyboard nav, focus trap, mobile swipe, and
  shareable deep links (`#work-3`); browser Back closes it. With JS off, each piece is a
  real link to its full-size image.
- **Optimized images** — every photo ships as WebP + JPEG via `<picture>` (WebP first,
  JPEG fallback, ~23% smaller). The gallery loads the `photos/web/` grid set; the lightbox
  loads larger versions on demand.
- **SEO / social** — per-page localized titles/descriptions, canonical + `hreflang`,
  Open Graph & Twitter cards with absolute image URLs, `Person`/`WebSite` JSON-LD, plus
  `robots.txt` and a `sitemap.xml` with language alternates.
- **Accessible** — WCAG-AA text contrast, a keyboard- and focus-trapped lightbox, an OS
  dark-mode default, and reduced-motion awareness.
- **Hardened & checked** — security headers via `vercel.json`; CI validates HTML, checks
  links, and runs a Lighthouse budget on every push.

## Build & run locally

The per-language pages are generated from `templates/` + `i18n.json` by `build.py`:

```bash
pip install beautifulsoup4
python build.py        # writes index/about + /ru /es /fr + sitemap.xml
npx serve .            # then open http://localhost:3000
```

Edit **`templates/`** and **`i18n.json`** — never the generated root/`ru`/`es`/`fr` files —
then re-run `build.py` and commit the result. `styles.css`, `app.js`, `photos/`,
`favicon.svg` and `robots.txt` are static and served from the site root.

Deployment is automatic: Vercel builds a preview for every branch/PR and ships `main` to
production. It serves the committed output, so there's no server-side build to configure.

## Project structure

```
templates/               index.html + about.html source (English, with data-i18n slots)
i18n.json                all translations (EN/RU/ES/FR) — single source of truth
build.py                 renders templates + i18n.json -> per-language pages + sitemap.xml
index.html, about.html   generated English pages (committed)
ru/, es/, fr/            generated localized pages (committed)
styles.css               all styles (design tokens, themes, layout, lightbox)
app.js                   behavior only (theme, nav, reveal, lightbox) — no i18n
favicon.svg              tumar-lozenge mark
robots.txt               crawl directives; sitemap.xml is generated by build.py
vercel.json              security headers + long-cache for /photos
optimize_images.py       regenerate photos/web/ from originals (needs Pillow)
photos/web/              optimized images (.jpg + .webp) used by the site (committed)
photos/web/large/        larger versions (.jpg + .webp) for the lightbox
.github/workflows/ci.yml HTML validation, link check, Lighthouse budget
```

> The original high-resolution photographs and `Turart Photos.zip` are **not** committed
> (they're large and live on the artist's machine). Run `python optimize_images.py` after
> dropping new originals into `photos/Turarts/` to regenerate the optimized set.

  `https://turar.art` placeholder. Point them at the real origin once and rebuild:
  `SITE_URL=https://yourdomain.com python build.py`, then update the `Sitemap:` line in
  `robots.txt`. (Absolute URLs are required for social previews and hreflang.)
- **Email** — the inquiry button points to a placeholder `hello@turar.art`.
- **Instagram** — link is a placeholder.
- **Work titles** — the gallery uses descriptive placeholder titles; the artist's real
  titles (e.g. *Neural Network, Chalice of Love, Scarab, Roots of the Kin*) can be mapped
  to the corresponding photos.
